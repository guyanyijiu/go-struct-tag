# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-01-07
### Added
- Support for `goqu` struct tags.

## [0.3.1] - 2024-07-16
### Improved
- Custom tags now allow omission of field names.

## [0.3.0] - 2023-04-26
### Added
- Support for custom struct tags.

## [0.2.1] - 2023-01-03
### Added
- Support for the `redis` tag.

## [0.2.0] - 2022-12-25
### Added
- Support for `env`, `validate`, and `mapstructure` tags.
- Struct tag value auto-completion.

## [0.1.1] - 2022-08-12
### Added
- Support for `yaml` and `binding` tags.

## [0.1.0] - 2022-08-10
### Added
- Case styles: `snake`, `camel`, `pascal`, `constant`, `none`.
- Auto-completion for struct tag values.

### Improved
- Performance and behavior of the auto-completion logic.

### Fixed
- Various minor bugs.

## [0.0.1] - 2020-10-21
### Added
- Initial release.
- Supported tags: `json`, `bson`, `xorm`, `gorm`, `form`.
